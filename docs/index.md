## Releases

PROMOT ontology has got five kind of artefacts released in three formats (json, obo, owl):
* **promot**: equivalent to promot-full
* **promot-base**: components only
* **promot-full**: components and imports included
* **promot-non-classified**: full version that keeps all redundant axioms (for documentation and development purposes)
* **promot-simple**: PROMOT entities and axioms that involve PROMOT entities only

These releases are available on the [PROMOT initiative website](https://www.promotinitiative.com/), [Github](https://github.com/JuPoIm/promot), [Obofundry](http://obofoundry.org/) and [Bioportal](https://bioportal.bioontology.org/ontologies/).

If you look for a detailed description of the ontology, please go [here](OntologyDescription.md).
