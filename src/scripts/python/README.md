# Directory for customized python scripts 
# Dossier pour les scripts pythons du projet

## scripts
- CIFASIP-ICF_mapping.py

    script for mapping the IRIs between the 2026 ICF and the 2020 CIF-ASIP

- ICF_labels-es-fr.py

    script for creating a ROBOT template with the French and Spanish translations for the ICF labels

- relations-to-template.py

    script for creating a ROBOT template with promot-component-base and the translations template in src/templates/, and hand edited axioms files in data/promot/

### /tmp
Données téléchargées pour la personalisation des imports

- CIF-ASIP

    List of IRIs, codes and labels used in CIF-ASIP

- icf_import_iri

    List of the IRIs that PROMOT imports from ICF

- icf-to-cifasip_all

    mapping between ICF and CIF-ASIP IRIs

- icf-to-cifasip_promot

    mapping between ICF and CIF-ASIP IRIs for the ICF IRIs used in PROMOT only
