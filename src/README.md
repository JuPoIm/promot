# Directory for curating the PROMOT ontology
# Dossier des répertoires de développement et de maintenance de PROMOT ontology

## data
- imports:

    EN: manually or automaticaally downloaded data for customized imports

    FR: données téléchargées, manuellement ou automatiquement, pour les imports et les mappings personnalisés

- promot:

    EN: hand edited tsv files containing the majority of PROMOT specific axioms, will be automatically transformated in ROBOT template thanks to a python script.

    FR: fichiers tsv édités à la main, avec la majorité des axiomes spécifiques à PROMOT, ils sont transformés en template ROBOT par un script python.

- scripts:

    EN: Files containing the diseases codes and genes names used in PROMOT

    FR: fichiers avec les codes maladies et les noms des gènes utilisés par PROMOT

## mappings
EN:

SSSOM mappings between ICF classes and CIF-ASIP classes (automatically edited), SSSOM mapping between common data elements used in PROMOT and original common data elements IRIs (not always synonyms) (hand edited)

FR:

Mappings SSSOM entre les classes ICF et leur équivalents CIF-ASIP (édité automatiquement), mappings SSSOM entre les common data elements de PROMOT et les IRIs des common data elements originaux (pas toujours synonymes) (édité à la main)

## metadata
EN: 

PROMOT ontology metadata (editable), SSSOM metadata (hand edited)

FR:

métadonnées de PROMOT ontology (éditable à la main), métadonnées des mappings SSOM (édité à la main)

## ontology
EN:

repository for components, config, imports, promot.Makefile editing, etc.

FR:

dossier avec les components, la config, les imports, le promot.Makefile éditable, etc.

## scripts
EN:

ODK .sh scripts, customized python scripts

FR: 

scripts bash ODK, scripts python personnalisés

## sparql
EN:

ODK sparql and ru queries, customized sparql queries 

FR:

requêtes sparql et ru d'ODK, requêtes sparql personnalisées

## templates
EN:

hand edited 'promot-component-base' template with the principal PROMOT specific axioms and automatically generated templates

FR:

template 'promot-componenet-base' édité à la main et templates générés automatiquements
