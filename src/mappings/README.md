# Directory for managing SSSOM mappings files

ICF_to_CIF_all-mappings.sssom
    -> SSSOM mappings file of ICF entities to french CIF-ASIP Ontology by LIRMM
ICF_to_CIF_promot-mappings.sssom
    -> SSSOM mappings file of ICF entities to french CIF-ASIP by LIRMM only for the ICF entities used in PROMOT ontology
promot_mappings.sssom
    -> SSSOM mappings file of PROMOT specific entities (PROMOT IRI) to existing ontology (SNOMED, NCIT, etc.)
